# Security

Please report suspected vulnerabilities privately to the repository owner rather than opening a public issue containing exploit details or secrets.

Never include Hermes backend URLs containing credentials, dashboard tokens, provider keys, session exports, unredacted logs or diagnostic bundles in a report. A minimal reproduction using the fake backend is preferred.

The current security design and remaining risks are tracked in [`docs/security/threat-model.md`](docs/security/threat-model.md).
